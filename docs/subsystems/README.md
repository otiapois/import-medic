## Review Checklist (DOER != CHECKER)
1. Identify affected subsystem(s) and verify every contract link still matches actual file paths and symbols.
2. Replay every dirty-CSV fixture using its original bytes. Re-validate the actual output bytes when export is available, and assert that unsafe inputs produce the expected review issues and withhold native CSV downloads.
3. Verify `npm run typecheck`, `npm test`, `npm run test:fuzz`, `npm run build`, and `npm run test:e2e` (desktop + mobile) all pass on the reviewed HEAD.
4. Confirm zero outbound network requests occur during file upload, diagnosis, repair, and download.
5. Recompute SHA-256 from the original files and actual CSV downloads. Compare the values with the workbench, JSON audit, and offline sign-off. Check that a held export has no output checksum.
6. Inspect the actual native update and rollback against their original baseline. Confirm that the inspector rejects a forbidden column and a changed SKU. Check scope agreement with the baseline alone and full catalog recovery with the matched update available.
7. Export the committed public source to a new directory, check that it excludes `docs/research` and `docs/tasks`, and run `tsc --noEmit` using the exported project configuration and the locked release dependencies.
8. Replay a valid and broken running-balance file. Match the verified link counts, physical lines, balances, and held status across screen, JSON audit, and offline Bookkeeper Sign-Off. Check that a FreshBooks mixed-currency file holds and a single-currency expense file passes local byte validation.
9. Configure branding with HTML-like text and open the downloaded sign-offs offline. Compare the rendered text, asset policy, and file fingerprints. Apply an eligible pricing scenario and compare the preview to the native update cells and totals.
10. Replay a nested BOM using supplier component costs and baseline fallbacks, and match the kit prices and BOM fingerprint in the native pair and reports. Replay a cyclic or unpriced BOM and check that both native files and their digests are held while the diagnostic retains its source lines.
11. Run all explicit CLI modes in local subprocesses. Check safe and held exit codes, diagnostic-only output on holds, and SHA-256 against the actual input and output bytes. Compare a legacy repair's stdout and audit bytes with the previous release.
12. Replay the inventory update and rollback from downloaded bytes with the expected current values enforced in both directions. Check exact restoration of the selected location's original quantity text and preservation of all other locations. Test missing location selection, conflicting stock, and a large drop with and without approval.
13. Replay four labeled supplier periods and check exact threshold inclusion, lifecycle with gaps, and margin against one retail price. Open the downloaded branded Vendor Negotiation Brief offline. Check the source and CSV hashes in its footer, the exact HTML hash in the separate audit, and the source evidence and missing output digests on a conflicting-duplicate hold.
14. Replay Amazon files with tab and comma delimiters. Check exact SKU text, inclusive price limits, original price and quantity text in the rollback, and preservation of every other catalog cell. Verify the actual matched pair and confirm that an unsafe price holds the native files.
15. Verify a one-cent VAT discrepancy and exact duplicate transaction line pairs. Compare source evidence in Issues & Review, JSON, and the offline Bookkeeper Sign-Off. Check that the repaired CSV is held and the flagged transactions remain available for review.
16. Replay a split purchase order at the exact reorder point and compare the quantities after MOQ and case-pack rounding, the exact cent subtotals, and the selected location. Check the downloaded supplier CSVs, summary CSV, and branded HTML against the audit digests. Replay an exact lowest-subtotal tie and an invalid offer, and check that each hold retains source evidence and withholds the order files.
17. Reload a saved categorization rule pack. Re-parse the actual CSVs and compare each signed net and tax split and the per-currency summary. Replay a conflicting pack and an unmatched amount above the review threshold. Check physical lines and rule IDs, audit-only output, and SHA-256 from the original CSV and rule JSON. Open the ready report offline and verify the selected branding.
18. Replay a wholesale run with three tiers, a MAP hold, and a cost or margin hold. Compare the rounded unit prices and case-pack-aligned minimums in the actual buyer CSV, offline HTML, and selected-tier Shopify catalog CSV. Compare each file with its allowed fields and verify fingerprints from the original and emitted bytes. Check that the audit retains the SKU, tier, and source-line evidence when pricing and matrix files are held.
19. Replay the catalog hygiene ready and held cases. Verify leading zeros and physical line references, including collisions across files. Inspect the exact cleaned cell changes, compare each rollback with the original bytes, and open the branded report offline. Verify the hashes of emitted files and the absence of catalog files and their digests on hold.
20. Replay payout reconciliation with exact matches, a missing deposit, a connected tie, and a one-cent shortfall. Verify the candidate lines and the exact per-currency partition for both sources, including retained proven pairs on a partial run. Confirm that invalid source evidence suppresses all pair rows. Compare SHA-256 for the original files and each emitted review artifact. Open the branded sign-off offline.
21. Replay a shipment by value and weight. Check each shared charge's exact cent sum, the duty base and per-line rounding, the exact landed total, and the separate four-decimal and whole-cent cost columns. Re-parse the downloads and verify their hashes, the original SKU text, and its downstream cost mapping. Open the branded HTML offline. Check that missing required weight or CBM holds the CSV and HTML and retains the physical source line in the audit.
